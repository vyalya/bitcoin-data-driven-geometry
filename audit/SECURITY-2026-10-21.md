# Bitcoin geometry security review

Checked October 21, 2026 UTC, following the production release at commit `79eed61`.

## Result

No credential disclosure was found in the tested production responses, built site or available Git history. Gitleaks 8.30.1 scanned 110 commits and the production build with zero findings. A fresh `npm audit`, including development dependencies, reported zero known vulnerabilities. These checks do not establish the absence of every possible vulnerability or reconstruct earlier request responses.

The deployed app is a static visualization. Its JSON contains public Bitcoin measurements and event sources. The app has no login, user database, upload route, order-processing API, or production filesystem-reading handler. Client code uses React text rendering; no application `eval`, HTML injection sink, or runtime credential access was found. Only the built `dist/` directory was uploaded to Pages.

## Suspicious requests and HTTP 200

Read-only checks of `/.env`, `/.env.local`, `/.git/config`, `/userfiles`, `/admin/config.json`, the encoded traversal paths from the reported traffic, and a random nonexistent path all returned the exact public homepage bytes. No environment assignments, Git configuration or process environment contents were detected. HTTP 200 on those paths reflects Pages' SPA fallback, not successful file retrieval.

Cloudflare's requested-path analytics count requests. They do not establish that a file exists or that its contents were disclosed. The checks in this review generate additional analytics entries. Earlier response bodies and account audit logs were not available for review.

## Headers and prevention

Live responses include framing denial, MIME-sniffing protection, a restrictive feature policy, referrer policy and HSTS. An explicit Content Security Policy is a remaining defense-in-depth improvement. Returning a real 404 for unknown paths would make scanner results clearer; the current fallback does not expose local files.

Added Git exclusions for `.env`, `.env.*`, `.dev.vars*` and `.wrangler/`. No such secret files were found in this checkout or tracked history. No live asset changes were needed for these repository exclusions.

It did not include a browser penetration test or a Cloudflare account-log investigation.
